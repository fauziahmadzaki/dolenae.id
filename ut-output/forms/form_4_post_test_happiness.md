## Rumus untuk Google Sheets

```
# NPS (mis. kolom N1 berada di kolom G, baris 2..11)
Promotor  : =COUNTIF(G2:G11,">=9")
Detraktor : =COUNTIF(G2:G11,"<=6")
Total     : =COUNTA(G2:G11)
NPS       : =((COUNTIF(G2:G11,">=9")-COUNTIF(G2:G11,"<=6"))/COUNTA(G2:G11))*100

# CSAT (mis. C1 di kolom D)
=COUNTIF(D2:D11,">=4")/COUNTA(D2:D11)*100

# Rata-rata skala (mis. Trust score dari kolom H, I, J)
=AVERAGE(H2:J11)
```
